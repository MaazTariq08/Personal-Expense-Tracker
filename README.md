# Personal-Expense-Tracker
This is a simple python code which helps to keep track of your daily expenses. This is right now the most basic and beginner-friendly version. 
It allows users to record and save their daily expenses. 
Users can add,view,edit,delete and search their expenses.
They can also provide category summary by listing all the categories of the expenses along with their costs.
it also calculates and provide with the total spending.
